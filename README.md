# Excel Compare Pro

엑셀 데이터 비교·불일치 분석용 Windows 데스크톱 프로그램 (PySide6 / Qt Designer)

## 폴더 구조

```text
excel_compare_pro/
├─ main.py                   # 실행/비교/결과 조회/Excel 저장
├─ theme.qss                 # 화면 스타일
├─ ui/
│  └─ mainwindow.ui          # Qt Designer 편집용 UI
└─ README.md
```

## 실행 방법 (Windows PowerShell 또는 VS Code 터미널)

1. 다운로드한 ZIP 파일을 압축 해제합니다.
2. 압축 해제한 `excel_compare_pro` 폴더에서 터미널을 엽니다.
3. 아래 명령어를 순서대로 실행합니다.

```powershell
py -m pip install PySide6 openpyxl
py main.py
```

※ `py` 명령을 사용할 수 없으면 `python`으로 바꾸세요.

## 화면 수정

Qt Designer에서 `ui/mainwindow.ui` 파일을 열면 레이아웃을 수정할 수 있습니다. 색상·글꼴은 `theme.qss`에 분리되어 있습니다. `main.py`는 실행 위치와 관계없이 자신의 폴더에 있는 UI를 읽습니다.

## 기능

1. 기준 파일(A), 대상 파일(B) 선택 (`.xlsx`, `.xlsm`)
2. 파일별 시트, 헤더 행, 식별 키 열 선택
3. [비교 열 선택]에서 기준파일/대상파일 열을 쌍으로 지정하여 비교 (다른 헤더 지원, 여러 쌍 추가·삭제 가능). 미선택 시 식별 키의 존재 여부만 비교
4. 앞뒤 공백/영문 대소문자/빈 값 처리 옵션
5. 일치, 값 불일치, A에만 존재, B에만 존재, 중복 키, 키 누락 표시
6. 상태별 필터·문자열 검색·Excel 결과 저장

## 유의사항

- 수식 문자열이 아니라 파일에 **저장된 계산 결과값**을 비교합니다. Excel에서 계산 후 저장하지 않은 수식 셀은 빈 값으로 읽힐 수 있습니다.
- 식별 키가 중복된 데이터는 잘못된 1:1 대조를 방지하기 위해 별도 상태로 표시합니다.
- 지표의 불일치는 **식별 키 건수**이며, 하나의 키에 서로 다른 열이 여러 개면 결과 표에는 여러 행이 나옵니다.
- 화면은 필터된 결과를 최대 5,000행 표시하며, Excel로 저장할 때는 전체 비교 결과를 포함합니다.
- 파일 처리는 사용자 PC에서 이뤄지며 서버 전송 기능은 없습니다.

이 소스는 기본 기능을 동작시키는 MVP이며, 대용량 처리나 상용 배포 전에는 추가 테스트를 권장합니다.
